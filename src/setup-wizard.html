What Dr. Vibe watches
All of this stays on this computer.
  • The name and title of the window in front, every few seconds, to tell when you are coding. Titles never leave this computer.
  • Time since your last key or mouse input (never what you type).
  • File changes and git activity (branch, commit messages) in the repos Dr. Vibe tracks.
You can pause tracking any time from the tray menu.

What Dr. Vibe sends
You choose what leaves this computer. Each switch stops that data here, before anything is sent.
  • On this computer only: window titles, file paths, repo names, git details, Claude Code file paths.
  • Sent only if you join the community: coding time and streaks, totals (never names), achievements, your look, and what you allow below.
  • Never sent: file contents, code, window titles, file or repo paths, your computer or login name.
Profile, leaderboards, project name, activity times, coding now, Vibe Map, visits and the recap apply if you join, now or later. Crash reports apply either way.
